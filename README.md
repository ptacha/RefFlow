# RefFlow

Automatisierte Erstellung von Referenzlisten.

Die Verarbeitung erfolgt lokal auf dem Computer und ohne Internetverbindung. Die Originaldateien bleiben unverändert.

## Entwickler

Ursprüngliche Idee, Konzeption und Umsetzung: Andrey Shpak.

## Entwicklungshinweis
